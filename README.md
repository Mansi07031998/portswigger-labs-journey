# PortSwigger Web Security Labs Journey

## About Me
Hi, I’m Mansi.

I’m an Application Security / Cybersecurity professional focused on building stronger hands-on skills in web application security, vulnerability analysis, penetration testing, and secure development practices.

## What This Repository Is
This repository documents my learning journey through PortSwigger Web Security Academy labs.

I’m using this space to:
- track my progress consistently
- document what I learn from each lab
- strengthen my understanding of web vulnerabilities
- practice writing clear, structured security reports
- build a portfolio that reflects my technical growth

## Why I’m Doing This
I spend a lot of time learning, but I do not always track that learning in a structured way. When I want to revisit and revise something I studied earlier, I often realize I have not documented it well enough to recall it clearly.

This repository is my way of fixing that.

I created this space to track what I practice, what I learn, and how my understanding evolves over time. Publishing my learning on GitHub also helps me stay consistent, accountable, and honest with my own goal of continuous improvement.

At the same time, I want to become better at explaining vulnerabilities clearly, including their impact, root cause, and remediation.
